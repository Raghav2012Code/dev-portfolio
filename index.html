02 — Projects

Selected work

Hardware-first projects, built for real competitions.

Featured · Overall Winner · Gold

Door Hinge Safety System

Robowunder International Robotics Championship 2025 · Malaysia

A hardware safety system designed to help prevent finger injuries around door hinges. Laser and IR sensors watch the hinge danger zone, and when something is detected inside it, the servo and solenoid actuators respond.

Sense — Laser + IR sensor → Process — ESP32 → Actuate — Servo + Solenoid

ESP32 · Laser sensor · IR sensor · Servo · Solenoid

Zonal Robotics Championship · SRM Chennai

Road Accident Safety Hub

Qualified for NRC Technoxian through the zonal championship

A robotics competition project that uses public accident data and XGBoost to predict where accidents may occur. It looks at parameters like time, day, junction information, and other relevant public-data parameters.

Contribution — Vibe-coding/software implementation and backend integration. The team handled frontend and testing.

XGBoost · Python · Public accident data

PEC Hacks 4.0 · Panimalar Engineering College · High School Track

Vaccine Cold Chain Ledger

Consolation Prize

A hardware-integrated cold-chain monitoring system: a DHT22 sensor tracks vaccine storage temperature via Arduino/ESP32, shows readings on an LCD, and records SHA-256-hashed data to Supabase for display in a web application.

DHT22 sensor→ Arduino / ESP32→ LCD→ SHA-256 hashing→ Supabase→ Web app

Contribution — Complete full-stack software implementation, including hardware/software integration.

Arduino · ESP32 · DHT22 · LCD · React · Next.js · TypeScript · Supabase · REST API · SHA-256
