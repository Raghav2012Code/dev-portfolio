★ FEATURED PROJECT

Door Hinge Safety System

Robowunder International Robotics Championship 2025 · Malaysia · Overall Winner

WINNER

A child-safety system designed to help prevent finger injuries around door hinges. The system uses sensors to detect when a hand is present near the hinge and actuates the mechanism to prevent the dangerous situation.

01 · SENSE

Laser + IR sensor

Detects a hand near the hinge

02 · PROCESS

ESP32

Reads sensors, decides response

03 · ACTUATE

Servo + Solenoid

Actuates the safety mechanism

Vaccine Cold Chain Ledger

Consolation Prize

A hardware-integrated cold-chain monitoring system that records real-time vaccine storage temperature and makes the information available through a web application.

  1. DHT22 temperature sensor
  2. Arduino / ESP32
  3. Temperature data
  4. SHA-256 hashing
  5. Supabase
  6. Web application

The system uses a DHT22 to record real-time temperature and displays the information through the web application.
